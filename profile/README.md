# Aquafall [OS]  
  
Welcome to Aquafall, a web operating system inspired by ArcOS.    
  
## Why does Aquafall exist?  
  
Aquafall was created to fill the gap of [ArcOS](https://github.com/IzK-ArcOS), as they recently announced their shutdown. We're still going, even if they're back!
We've scrapped Aquafall v1 and moved onto [v2!](https://github.com/Aquafall/v2/)

## So, what is Aquafall?
  
It's just like ArcOS, a web operating system made in Svelte, however we use JavaScript instead of TypeScript. This is not a rebrand of ArcOS.  

## Is Aquafall compatible with ArcOS?  
  
If people want the APIs to be ArcOS-Compatible and Aquafall to be compatible with ArcAPIs, we can try to implement this.
## ArcOS exists again, no need for this BUT plans are in place for an ArcOS compatibility layer with an accounts system for v2.
